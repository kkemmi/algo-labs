Лаболаторна робота №1 (Варіант 3 Рівень 3) 
Дано одновимірний масив цілих чисел 'array'
Перевірте, чи існують у масиві вершини, які утворюють найдовший пік у 'array', де елементи спочатку строго зростають до вершини, а потім строго спадають
Якщо такі піки існують, поверніть максимальну довжину знайденого піку.
