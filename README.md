Лабораторна робота 5 
Обчислення кількості островів
Опис
Дано двійкову матрицю, де:
0 — вода
1 — суша
Потрібно визначити кількість островів. Острів — це група сусідніх клітин зі значенням 1, які з’єднані по горизонталі або вертикалі.

Ідея розв’язку
Для розв’язання задачі використовується обхід матриці. Кожного разу, коли знаходиться клітинка із значенням 1, запускається алгоритм обходу (DFS або BFS), який позначає всі клітинки цього острова як відвідані.
Таким чином підраховується кількість окремих островів.

Результат
Для заданої матриці було визначено, що вона містить 5 островів.
