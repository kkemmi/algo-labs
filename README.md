# Лабораторна робота 4

## Опис
Реалізувати структуру даних "черга з пріоритетами" на основі червоно-чорного дерева.

У дереві виконується умова:
- батьківський елемент має вищий пріоритет, ніж правий нащадок
- або нижчий/рівний пріоритет, ніж лівий нащадок

## Операції
Черга повинна підтримувати:
1. Вставку елемента (значення + пріоритет)
2. Видалення та повернення елемента з найвищим пріоритетом
3. Перегляд елемента з найвищим пріоритетом без видалення

## Реалізація
- Використовується червоно-чорне дерево
- Кожен елемент — об'єкт класу Node:
  - value — значення
  - priority — пріоритет

Файл реалізації:
red_black_priority_queue.py

## Структура проєкту
- red_black_priority_queue.py — основний код
