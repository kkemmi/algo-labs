# Лабораторна робота 1

## Опис
Реалізувати функцію, яка приймає невпорядкований масив цілих чисел і повертає довжину найдовшої пікової підпослідовності.

## Пікова підпослідовність
Це послідовність, яка:
- спочатку строго зростає
- має максимум (пік)
- потім строго спадає

Мінімальна довжина — 3 елементи.

## Приклад
Вхід:
[1, 3, 5, 4, 2, 8, 3]

Вихід:
5

Пояснення:
Найдовша підпослідовність: 1, 3, 5, 4, 2

## Структура проєкту
- main.py — основний код
- test.py — тести
- README.md — опис

## Запуск
python main.py

## Тести
python -m unittest test.py

## Оцінювання
Варіант:
(номер у списку mod 3) + 1

Рівні:
1 рівень — до 0.7  
2 рівень — до 1  
3 рівень — до 1.2
