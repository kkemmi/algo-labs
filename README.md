Лаболаторна робота №2 (Варіант 3 Рівень 3) 
Дано координати стійл 'stalls', їх кількість 'n' та кількість корів 'c'
Перевірте, яку найбільшу можливу мінімальну відстань між коровами можна отримати 'stalls', розставивши усіх корів у стійлах так, щоб вони не билися
Якщо корів більше ніж одна, поверніть максимальне значення цієї мінімальної відстані.
