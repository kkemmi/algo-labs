# Лабораторна робота 2

## Опис
Реалізувати функцію, яка приймає:
- N — кількість елементів
- C — деяке порогове значення
- масив free_sections

Функція повинна повернути кількість елементів масиву, які більші або рівні C.

## Приклад
Вхід:
N = 5  
C = 3  
free_sections = [1, 2, 8, 4, 9]

Вихід:
3

Пояснення:
Елементи ≥ 3: 8, 4, 9 → всього 3
