Дано бінарне дерево 'BinaryTree' з кореневим вузлом 'tree'
Перевірте, яка максимальна довжина шляху між будь-якими двома вузлами в 'tree', що визначає діаметр цього дерева (шлях може проходити або не проходити через корінь)
Якщо дерево містить вузли, поверніть числове значення знайденого діаметра.
