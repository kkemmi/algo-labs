Lab 3

Тема

Обчислення максимального діаметра бінарного дерева та візуалізація дерева
Умова задачі

Потрібно реалізувати функцію для обчислення максимального діаметра бінарного дерева.
Діаметр дерева — це найбільша відстань між будь-якими двома листками (кінцевими вузлами). Відстань вимірюється як кількість ребер між ними.
Максимальний діаметр не обов'язково проходить через корінь.
Вхідні дані

Корінь бінарного дерева (об'єкт класу BinaryTree)
Вихідні дані

Максимальний діаметр дерева
Реалізація

Клас бінарного дерева:
class BinaryTree:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right
