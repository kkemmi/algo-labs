Виконала: Козловська Катерина Андріївна (ІР-11) 
Лаболаторна робота №8 (Варіант 3 Рівень 2) 
Дано кількість слів 'n' та масив слів 'words'
Перевірте, яку максимальну довжину ланцюжка слів можна побудувати з масиву 'words', видаляючи по одній літері з кожного наступного
слова так, щоб нове слово також існувало в масиві.
Якщо такі ланцюжки існують, поверніть найбільшу довжину знайденого ланцюжка.
